# BlockGen - Unity3d

A basic voxel engine in unity, to generate millions of blocks
Note: The latest source code is currently available on the 'dev' branch.

setup:
download the source code and open it with unity engine

Features:
easy to use 
terrain and player example
procedural terrain genration

Controls: 
| Move            | WASD               |
| Look            | Mouse              |
| Jump            | Space              |
| Place Block     | Left Mouse Button  |
| Break Block     | Right Mouse Button |
| Toggle Fly Mode | Double Jump        |
